# D-Mart Retail Business Dashboard

## 📌 Project Overview

This project presents an **interactive D-Mart Retail Business Dashboard** created using Excel.

The dashboard was developed using **PivotTables, PivotCharts, KPI cards, and Slicers** to analyze and visualize important sales and business performance metrics.

The dashboard provides an interactive way to explore D-Mart retail sales data across different regions, categories, cities, customer types, and months.

## 🎯 Objectives

- Analyze D-Mart retail sales data
- Create an interactive business dashboard
- Summarize data using PivotTables
- Create different PivotCharts for visualization
- Use KPI cards to display important business metrics
- Add Slicers for interactive filtering
- Analyze sales, profit, quantity, and discount
- Compare regional, category-wise, city-wise, and customer-wise performance

## 📊 Dashboard Analysis

The dashboard includes the following analyses:

### 1. Region-wise Sum of Sales
Analyzes total sales generated across different regions.

### 2. Category-wise Sum of Sales
Compares sales performance across different product categories.

### 3. City-wise Sum of Sales
Shows total sales generated by different cities.

### 4. Region-wise Sum of Profit
Compares total profit generated across different regions.

### 5. Category-wise Sum of Profit
Analyzes profit contribution from different product categories.

### 6. Customer Type-wise Sum of Sales
Compares sales generated by different customer types such as Member, Normal, and Regular.

### 7. Order Month-wise Sum of Profit
Shows monthly profit performance and helps identify changes in profitability over time.

### 8. Top 5 City-wise Sum of Profit
Highlights the top 5 cities based on total profit.

### 9. Category-wise Sum of Discount
Analyzes the total discount provided across different product categories.

### 10. Category-wise Sum of Quantity
Compares the quantity sold across different categories.

## 📌 KPI Cards

The dashboard includes KPI cards for quick business-level understanding, including:

- Total Sales
- Net Revenue
- Number of Regions
- Number of Categories

These KPIs provide a quick summary of important metrics before exploring the detailed charts.

## 🎛️ Interactive Slicers

Slicers were added to make the dashboard interactive.

The dashboard includes slicers for:

- Region
- Customer Type

Users can select different values from the slicers to filter and explore the dashboard dynamically.

## 📈 Dashboard Visualizations

Different PivotChart types were used to represent the analysis, including:

- Column Charts
- Bar Charts
- Pie Charts
- Line Charts
- Doughnut/Pie-style Charts
- Top 5 comparison charts

Different chart types were selected based on the type of data being analyzed.
